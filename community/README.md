# Community repositories

This folder is a curated index of **external Seanime repositories**.

Nothing listed here is copied automatically into the AleBoss72 marketplace. Each project remains maintained by its original author. The goal is to keep a convenient list of additional sources, plugins and marketplaces that may be useful alongside this repository.
