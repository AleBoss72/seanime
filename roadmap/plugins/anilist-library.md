# AniList and library plugins

- ◻ **AniList Activity** — view your own and friends' AniList activity inside Seanime.
- ◻ **AniList Notifications** — surface AniList notifications inside Seanime.
- ◻ **AniList Favorites** — expose/manage AniList favorites.
- ◻ **AniList Forums** — access AniList forum content from Seanime.
- ◻ **AniList Watch Order** — show recommended watch order from an anime page.
- ◻ **AniList Autopause** — automate list status changes to Paused in selected situations.
- ◻ **AniList Private** — additional controls for private AniList entries.
- ◻ **Account Switcher** — switch quickly between multiple AniList accounts.
- ◻ **Random Entry** — pick a random title from the library.
- ◻ **Vault** — create and manage curated personal lists.
- ◻ **Untracked** — identify media that is not tracked correctly.
