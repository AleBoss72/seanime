# UI and reader plugins

- ✅ **Reader Enhancer** — our manga reader enhancement plugin.
- ◻ **Library Grid Layout** — customize the number/layout of cards in library views.
- ◻ **Alternative Titles** — choose which title variant Seanime displays.
- ◻ **Custom Banner Images** — replace anime/manga banner images.
- ◻ **Custom Cover Images** — replace anime/manga cover images.
- ◻ **Custom Episode Metadata** — override episode metadata.
- ◻ **Custom CSS Manager** — manage custom CSS from inside Seanime.
- ◻ **Fancy Fonts** — customize interface fonts.
- ◻ **Score Extended** — extend score/rating display and controls.
- ◻ **No Cap Ratings** — modify rating display/limitations.
- ◻ **Quick Access** — add shortcuts and quick navigation controls.
- ◻ **Oneko.js** — decorative cursor-following cat.
- ◻ **Snow Effect** — seasonal visual effect.
