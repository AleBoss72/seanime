# Italian providers

## Anime

- ✅ **AnimeWorld** — Italian sub/dub streaming provider.
- ✅ **AnimeUnity** — Italian sub/dub streaming provider.
- ◻ **AnimeUnity (Mirror)** — independent mirror/fallback implementation for AnimeUnity.
- ◻ **AnimeSaturn** — Italian sub/dub streaming provider.
- ◻ **AnimeSaturn (Mirror)** — fallback/mirror implementation for AnimeSaturn.

## Manga

- ✅ **MangaWorld** — Italian manga provider.

## Notes

Recommended priority:
1. AnimeSaturn
2. AnimeSaturn (Mirror)
3. AnimeUnity (Mirror)

The mirror providers are useful as fallback paths when the primary domain/API is unavailable.
